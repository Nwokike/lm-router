# Phase 6 Implementation Plan: Build Packaging, Assets & Lint Hardening (Final Phase)

### Objective
Close out the roadmap by hardening everything the `flet-cli` and `ruff` studies verified as broken, dead, or loose:
1. Remove the proven-dead boot-screen config key (silently ignored by flet-cli 1.0.0).
2. Trim the Android release target architectures and pin the bundled Python interpreter.
3. Fix `cleanup.app_files` globs that never match (dead config giving false confidence).
4. Enable the small, real-value ruff rule set (`COM812`, `RUF`, `SIM105`) and fix every hit; scope `T201` to scripts where prints are the CLI interface; fix `B009`.
5. Validate `engine_version` with PEP 440 (`packaging.Version`) inside `scripts/fetch_engine.py` so a bad upstream token can never poison `version.json`.
6. Document that `icon.svg` is never consumed by the build pipeline (Flet filters `.svg`; `icon.png` is the effective source).

**No art generation** (splash.png / icon_android.png stay out of scope — the derived-shrink path from `icon.png` is correct for an icon-derived logo, per the flet-platform-assets study).

## Detailed Task Breakdown for Phase 6

### 1. `pyproject.toml` Hardening (keys verified against flet_cli 1.0.0 source)
- **Delete dead boot-screen block**: remove `[tool.flet.app.boot_screen]` entirely — `_resolve_boot_screen()` only reads `[tool.flet.boot_screen]`, so `startup_message` is a silent no-op. Leave a short comment so nobody restores it.
- **Trim release ABIs**: `target_arch = ["arm64-v8a"]` (x86_64 is emulator-only and roughly doubles native payload). Keep `x86_64` mentioned in a comment for an emulator flavor.
- **Pin the interpreter band**: `requires-python = ">=3.14,<3.15"` so a flet-cli/python-build manifest bump can never silently switch the bundled runtime to 3.15.
- **Fix `cleanup.app_files`**: globs run inside the packaged app dir (`src/`), so root-relative `tests/scripts/tools/screenshots` entries never match — remove them with a comment explaining the scope (repo-root dirs are outside the package anyway).
- **Lint config**: add `COM812`, `RUF`, `SIM105` to `lint.select`; add per-file-ignore `"scripts/*" = ["T201"]` (prints *are* the CLI's output; skipping `scripts/` entirely would also skip `S` checks).

### 2. Auto-fixes & Small Code Fixes for the Newly Enabled Rules
- `ruff check --fix` for `COM812` (missing trailing commas, all auto-fixable).
- `RUF` real hits:
  - `src/core/tokens.py`: sort `__all__`.
  - `src/screens/onboarding_screen.py`: store the floating `asyncio.create_task(...)` result in a reference.
  - `src/services/engine.py`: remove the stale `# noqa: S310` (RUF100) but keep the audit-trail comment explaining the URL is an app-controlled constant.
- `SIM105` (4 hits): convert `try/except/pass` → `contextlib.suppress(...)` in `src/core/settings.py`, `src/services/ad_service.py`, `src/services/history.py`, `tests/test_render.py`.
- `B009` (1 hit): `tests/test_engine_service.py` — `getattr(svc._mod, "acquire_server")` → direct attribute access.

Deliberately NOT enabled now: `N802` (fights `@ft.component PascalCase`), `ARG005` (flet `(e)` callbacks intentionally unused), `BLE/PL/EM/TRY` wholesale (need file-by-file triage), `INP001` (no `__init__.py` by design).

### 3. PEP 440 Validation in `scripts/fetch_engine.py`
- Extract a testable helper `_extract_engine_version(data: bytes) -> str` that:
  - finds the `VERSION` token,
  - parses it with `packaging.version.Version`,
  - raises `ValueError` on invalid versions,
  - returns `str(Version(...))` (normalized).
- Wire it into `main()` so an upstream malformed version fails loudly instead of writing junk into `version.json`.
- Import `packaging` directly (now a declared dependency since Phase 4).

### 4. Asset Documentation
- Add a one-line comment in `pyproject.toml` `[tool.flet]` (near `icon_background`) noting `src/assets/icon.svg` is NOT consumed by flet-cli (it filters `.svg`; `icon.png` is the source of truth) — keeps the file as design master without implying a vector pipeline exists.

### 5. Tests for Phase 6
- Add `tests/test_fetch_engine.py`:
  - `_extract_engine_version` accepts valid PEP 440 (`1.0.0`, `1.2.0rc1`), rejects garbage, raises on missing token.
- Add config-guard assertions to `tests/test_version_sync.py`:
  - `requires-python` contains `,<3.15` (interpreter pin present).
  - `target_arch` does not include `x86_64`.
  - No `[tool.flet.app.boot_screen]` section (dead key stays dead).
